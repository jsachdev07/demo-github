# Git Playground

A dummy project for practicing git.

## Files
- `notes.txt` – a simple text file you can edit to practice commits
- `app.py` – a tiny script you can change to practice diffs/merges

## Suggested exercises
1. Check status/history: `git status`, `git log --oneline`
2. Make a change to `notes.txt`, then `git add` + `git commit`
3. Create a branch: `git checkout -b feature-1`, make changes, commit
4. Switch back to `main` and merge: `git checkout main`, `git merge feature-1`
5. Try a conflict: edit the same line of `notes.txt` on two branches, then merge
6. Practice `git stash`, `git rebase`, `git cherry-pick`, `git reset`, `git revert`
7. Tag a release: `git tag v1.0`
